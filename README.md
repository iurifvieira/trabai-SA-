# Projeto Situação de Aprendizagem (SA)

Site institucional desenvolvido para a entrega do projeto integrado do curso de aprendizagem industrial do senai.

##  Tecnologias Utilizadas
- HTML5
- CSS3

##  Como visualizar o projeto localmente
1. Faça o clone deste repositório ou baixe o arquivo ZIP.
2. Abra a pasta do projeto no seu computador.
3. Dê um duplo clique no arquivo `index.html` para abrir no navegador.
